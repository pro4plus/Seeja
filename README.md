# السيجا السودانية — Alseeja v4

تطبيق أندرويد مبني بالكامل بلغة Flutter يحاكي لعبة السيجا السودانية التراثية في أجواء الحوش السوداني عند الغروب.

## التشغيل وبناء APK تلقائياً عبر GitHub
بمجرد رفع هذا المشروع إلى فرع `main` على GitHub، سيعمل ملف `.github/workflows/build-apk.yml` تلقائياً على توليد ملف `app-release.apk` ويمكنك تحميله من تبويب **Actions -> Artifacts -> alseeja-apk**.
