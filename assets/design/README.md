# حزمة تصميم السيجا — Alseeja Design Kit

كل عنصر من الشاشات المرفقة مرسوم كملف **SVG** منفصل (قابل للتكبير بلا فقدان)، ومعه نسخة **PNG بخلفية شفافة** بدقة 2×.

## المجلدات
- `svg/` و `png/` (نفس الهيكل والأسماء):
  - `characters/` — الشيخ الجالس (بنظارة / للرئيسية)، وصدريات الاختيار: ود البلد، الأستاذ، الشيخ
  - `pebbles/` — الحصى السبعة (نيلي، كهرماني، فيروزي، أحمر، أخضر، طيني، فحمي)
  - `board/` — لوحة 5×5 و7×7، وعلامات: الخانة المتاحة، التحديد، آخر حركة، نجمة الوسط
  - `objects/` — صحون الطين (فارغ / حجارة بنية / حجارة نيلية)، الفانوس (مضيء / عادي)
  - `plates/` — الأطباق الزخرفية الثلاثة (قوس قزح، أحمر، نجمة)
  - `scene/` — مشهد الباب مقسّم طبقات بنفس الإحداثيات (سماء، شمس، أهرامات، أرض ونيل، نخلة، إطار) + نسخة كاملة + نسخة مع الشيخ
  - `ui/` — الأزرار الدائرية وأيقوناتها (إيقاف، صوت، إعدادات، رجوع، تلميح، تراجع)، ألواح الأزرار (بدون نص وبنص)، زر «يلا»، كوّات اختيار الخصم، بطاقات حجم اللوحة، صينية الحصى، ورقة النتيجة وبطاقات الإحصاء، شريط الدور، قصاصات الاحتفال
  - `backgrounds/` — برش القش، أشرطة النسيج الأحمر والأسود، الأهداب، سجادة اللوحة، خلفية الرئيسية
  - `logo/` — شعار «السيجا»
  - `from_screenshots/` (PNG فقط) — قصاصات بالبكسلات الأصلية من لقطاتك: الشعار، الميدالية، أطباق الجدار
- `fonts/` — Reem Kufi وTajawal (تحتاجها ملفات SVG التي فيها نص، أي التي تنتهي بـ `_label` وملف الشعار)
- `reference/` — لقطاتك الأصلية للمقارنة
- `preview_sheet.png` — ورقة معاينة لكل العناصر

## ملاحظات
- العناصر التي تتراكب (طبقات الباب) لها نفس حجم اللوحة، فضعها فوق بعض بلا تحريك.
- ملفات SVG ذات النص تحمّل الخطوط من `../../fonts/`؛ في Figma أو Illustrator ثبّت الخطين من المجلد أولاً.
- الرسم مُعاد بالمتجهات بالاعتماد على لقطاتك، فهو قريب جداً لكنه ليس نسخة بكسل لبكسل. للنسخة المطابقة انظر `from_screenshots/`.
